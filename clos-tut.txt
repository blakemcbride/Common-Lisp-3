
CLOS Tutorial for the layer over CLOS in Common Lisp 3 (clos-utils.lisp).

Written by Blake McBride (blake@mcbridemail.com)

This tutorial assumes you know OO concepts coming from the Smalltalk,
Objective-C, C++, Java, or C# world.  It also assumes you have a
working knowledge of Common Lisp but little understanding of CLOS.

This tutorial assumes you have loaded Common Lisp 3 like:
    (load "cl3")
    (use-package :cl3)

1.  Class creation.

CLOS supports multiple inheritance.  The order of the super classes
specified determines the order that methods are searched.  The way
to create a class is outlined as follows:

(define-class class-name
           (super-class-list)
	   (class-variables)
	   (instance-variables)
	   (class-instance-variables))     ; optional, see section 5

For example:

(define-class my-class () (cv1) (iv1 iv2))

This creates a class named 'my-class' with one class variable (slot)
named 'cv1' and two instance variables (slots) named 'iv1' and 'iv2'.

A sub-class of my-class can be created as follows:

(define-class mysubclass (my-class) (cv2) (iv3))

This creates a class 'mysubclass' which is a sub-class of 'my-class',
adds a class variable (slot) named 'cv2', and an instance variable
(slot) named 'iv3'.  Because of inheritance, instances of mysubclass
have three instance variables iv1, iv2 and iv3.  Mysubclass has a class
variable 'cv2' and shares a class variable 'cv1' with the my-class
class.

As in Smalltalk, a class variable is one value shared by the class that
declares it and every subclass beneath it -- not a copy per class.
Setting 'cv1' through mysubclass changes the same value my-class reads,
and the other way round.  A class variable is not visible above the
class that declares it: 'cv2' belongs to mysubclass and below, and
my-class knows nothing of it.

2.  Creating instances

Create a variable i1 to contain an instance of my-class:

(defparameter i1 (make-instance my-class))

Create a variable i2 to contain an instance of mysubclass:

(defparameter i2 (make-instance mysubclass))

3.  Setting and getting instance variables

Set slot 'iv1' of instance 'i1' to 55:

(set-slot i1 'iv1 55)

Get the value of slot 'iv1' of instance 'i1':

(get-slot i1 'iv1)

4.  Setting and getting class variables

Set slot 'cv1' of class 'my-class' to 32:

(set-slot my-class 'cv1 32)

Get slot 'cv1' from class 'my-class':

(get-slot my-class 'cv1)

There is one 'cv1', shared down the hierarchy, so a subclass reads and
writes the same value:

(get-slot mysubclass 'cv1)      ->  32

(set-slot mysubclass 'cv1 64)

(get-slot my-class 'cv1)        ->  64

An instance reaches its class variables too, which is what lets a method
use them through 'self' (section 8):

(get-slot i1 'cv1)              ->  64

(set-slot i1 'cv1 70)           ; sets the one value the class shares

An instance variable takes precedence over a class variable of the same
name, so a name declared in both reaches the instance's own.


5.  The two kinds of class variable

Smalltalk has two kinds of class-side state, and so does this.  Sections
1 and 4 describe the first:

    class variables           one value, shared by the class that
                              declares it and every subclass

    class-instance variables  declared once, but every class in the
                              hierarchy has its own value

Class variables are the third argument to define-class and are what you
usually want: a setting, a registry, a limit that the whole hierarchy
agrees on.  Class-instance variables are the fifth and optional
argument, for when each class needs its own -- a per-class count, say:

(define-class shape ()
    (units)                 ; class variable: shared by every shape
    (x y)                   ; instance variables
    ((made :initform 0)))   ; class-instance variable: one count per class

(define-class circle (shape) () (radius) ())

Setting 'units' through circle changes what shape reads, because there
is one of it:

(set-slot circle 'units 'mm)

(get-slot shape 'units)         ->  mm

'made' behaves the other way: shape and circle each have their own,
each starting at 0.

(set-slot circle 'made 3)

(get-slot circle 'made)         ->  3

(get-slot shape 'made)          ->  0

A four-argument define-class, as in section 1, simply declares no
class-instance variables.


6.  Creating an instance method

The following creates an instance method named 'addiv' that takes two
arguments named 'ins' and 'val'.  The 'ins' argument is expected to be
an instance of 'my-class' or one of its sub-classes.  This method simply
adds val to the the value of the instances' instance variable 'iv1'.

(defmethod addiv ((ins my-class) val)
    (+ (get-slot ins 'iv1) val))

The new method can be used as follows:

(addiv i1 72)

7.  Creating a class method

The following creates a class method named 'addcv' that takes two
arguments named 'cls' and 'val'.  The 'cls' argument is expected to be
the class object 'my-class' or one of its sub-classes.  This method simply
adds val to the the value of the class' instance variable 'cv1'.

(defmethod addcv ((cls (eql my-class)) val)
    (+ (get-slot cls 'cv1) val))

The new method can be used as follows:

(addcv my-class 42)

8.  Creating a method with define-method

Sections 6 and 7 use CLOS' own defmethod, which works and gives you all
of CLOS.  define-method is a shorter form for the common case: a method
on one class that wants to reach the instance.  It binds the instance to
'self'.

(define-method addiv my-class (val)
    (+ (get-slot self 'iv1) val))

It is used the same way:

(addiv i1 72)

The argument list holds only the arguments after the instance; 'self' is
not written there.  A method taking nothing further has an empty list:

(define-method getiv my-class ()
    (get-slot self 'iv1))

Because an instance reaches its class variables, a method can keep
per-class state through 'self'.  This counts every instance ever made of
my-class or any of its subclasses, in one shared place:

(define-class my-class () (population) (iv1 iv2))

(set-slot my-class 'population 0)

(define-method census my-class ()
    (set-slot self 'population (+ (get-slot self 'population) 1)))

define-method takes no qualifiers and dispatches on one argument.  Where
you want :before, :after or :around, or dispatch on more than one
argument, use defmethod as in sections 6 and 7.


9.  Other facilities

Returns the class of an (class or instance) object

(class-of i1)

(class-of my-class)

Find a class object from its name:

(find-class 'my-class)

Get a class' name:

(class-name my-class)

Get the name of an object's class:

(type-of i1)

Access instance slots as local variables:

(with-slots (iv1 iv2) i1
   (setq iv1 17)
   (setq iv2 49))

CLOS standard way of accessing instance slots:

(slot-value i1 'iv1)

(setf (slot-value i1 'iv1) 32)

10.  Create a class with default slot values:

(define-class newclass ()
    ((cv1 :initform 42))
    ((iv1 :initform 36)
     (iv2 :initform 11)))

11.  Create a class with named initial values

(define-class class2 () ()
   ((iv1 :initarg :val)))

To use do:

(make-instance class2 :val 66)

This will create a new instance with iv1 set to 66.

     
12.  Instance initialization method

To run code whenever an instance is created, add an :after method to
CLOS' initialize-instance.  That needs a qualifier, so it is written
with defmethod rather than define-method:

(define-class counter () () (n))

(defmethod initialize-instance :after ((inst counter) &key)
  (set-slot inst 'n 0))

Every instance of counter then starts with n set to 0:

(get-slot (make-instance counter) 'n)
